# The Adventurer's Chronicle

A mod for [Ragnarok Offline](https://github.com/Flux159/ragnarokoffline.app).

Are you new to Ragnarok, or coming back after years and not sure where to go next? The Adventurer's Chronicle is a story-driven main quest. It walks you across Rune-Midgard at the right pace for your level, from Prontera's fields at level 1 to Odin's Temple past 99.

## What's in it

- **8 chapters** through Prontera, Payon, Morroc, Geffen, Glast Heim, Juno, Rachel and Hugel. The chapters retell Rune-Midgard's own lore: the weakening seals, Geffenia, the fall of Glast Heim, Juperos and The Sign.
- **Hunts, gathering and a named boss** in every region.
- **Quest EXP** carries you to the next quest's level. You can change the amount in the settings.
- **A costume of your choice** at the end of each chapter.
- **A journal** (Alt+B, or the button under the minimap). It recaps everything you've done and shows what to do next. Its Route link opens Navigation to the exact spot.
- **Veterans can skip ahead** to their level.

For travel, pair it with NPC Plus. Its Warper can unlock each place as you set foot in it.

## Install

In Ragnarok Offline, open **Mods → Find Mods** and install **adventurers-chronicle**. Updates show up there too.

To install by hand, download the zip from [Releases](../../releases), then install it from the Mods tab.

## Requirements

- Ragnarok Offline 1.4.8 or newer
- Pre-renewal

## Settings

- **Quest EXP (%)**: 100 gives exactly enough EXP to reach the next quest's level. 0 turns quest EXP off.
- **Show the Journal button**: Alt+B works either way.
